# Content preflight in the current Agent

Review the exact content intended for the audience, including visible text, images described or
embedded, linked destinations, generated examples, and Slides audience projection. Use the Agent's
current model and the current conversation; do not install a local model or call a separate paid
moderation service.

- Do not create or publish pornographic, gambling, or fraudulent content. For ambiguous educational,
  historical, medical, or reporting context, judge what the audience actually sees and ask for the
  missing context needed to decide. Do not mark the work safe merely because a title sounds benign.
- Apply an explicit applicable political-sensitive-content rule only when its scope is known. A
  political topic by itself is not prohibited. A timezone or language is a clue, not proof of the
  user's location or applicable jurisdiction. Ask for the relevant region when it materially changes
  the decision; do not invent a location or claim a legal determination from the timezone.
- On a clear prohibited result, stop publication and explain which audience-facing part needs to
  change. On uncertainty, state what is uncertain and the smallest useful clarification. Do not
  replace missing information with an invented pass verdict.

The Agent's conclusion is not a server-attested moderation decision. Onimi's ordinary publication
API checks fixed bytes, ownership, policy and document structure, and can be called by clients that
do not use this Skill. Never describe an ordinary publication as having passed platform semantic AI
review. Submission to the official gallery has its own human Admin review.
